## 🚀 Quick Start

1. **Setup Environment**
   ```bash
   ./setup.sh
   ```

2. **Start Development**
   ```bash
   # Backend
   cd backend && python start_backend.py
   
   # Frontend
   cd frontend && npm run dev
   ```

3. **Access Application**
   - Frontend: http://localhost:9890
   - Backend: http://localhost:8960
